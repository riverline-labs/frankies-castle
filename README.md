# Frankie's Castle

Haunted laboratory slot — five reels, play money only.

```
npm install
npm run dev
```

Open http://127.0.0.1:5173

## Models

- Blender scene: `blender/frankies_castle.blend`
- glTF: `public/models/` — `cabinet.glb`, `lever.glb`, and one file per symbol (`wolf`, `moth`, `bat`, `bride`, `creature`, `elixir`, `frank`)
- Rebuild: `blender --background --python blender/build_models.py`
